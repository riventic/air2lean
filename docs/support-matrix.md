# Current support matrix

This page is the one current support matrix. The marked region below is generated
from committed sources; do not edit it by hand:

- Zig versions: `supportedVersions` in `Air2Lean/Air/Normalize.lean`, the exporter
  pins in `zig-patch/versions.toml` and the default `AIR2LEAN_ZIG_VERSION` of the
  pipeline scripts;
- examples: `examples/*/zig-versions` through `scripts/example-selection.sh`, and
  the CI matrix in `.github/workflows/ci.yml`;
- compiler-derived inventory: `coverage/<version>.json` ([coverage](coverage.md));
- requirement status: the register in [ROADMAP.md](../ROADMAP.md).

```sh
python3 scripts/support-matrix.py generate   # rewrite the generated regions
python3 scripts/support-matrix.py check      # exit 1 if stale or inconsistent
python3 -m unittest discover -s tests/roadmap/support-matrix -v
```

`generate` rewrites this region and the `zig-versions` regions in
[README.md](../README.md#zig-versions) and [PLAN.md](../PLAN.md#zig-version-support).
`check` exits 1 when any region is stale, and also when these sources disagree:
the translator's supported versions, exporter pins, coverage inventories and CI
matrix versions; an explicit CI example list and the default selection; the
translator CLI `--help` (every supported version, the default, every flag in its
usage, a link to this page) and its `--diagnostics-json` usage; README's examples
table; ROADMAP's header counts and its register; and PLAN's
[current open work](../PLAN.md#current-open-work), which may name no `complete`
requirement, no item marked done and no historical milestone. Exit 2 means an
input is missing or unreadable. Neither mode starts Zig, Lake or Lean.

What the matrix does not establish: a selected example is translated, golden-checked
and proof-built in its CI job; only full jobs run the differential test. The
inventory is a source inventory, not support qualification. Requirement status is
the register's; a bounded merged slice leaves a requirement `partial` until its full
acceptance holds. [PLAN.md](../PLAN.md#historical-milestones) keeps the milestone
history (M0–T5) as historical scope; current open work is the register below.
