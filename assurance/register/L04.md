[PR125](https://github.com/riventic/air2lean/pull/125): whole-union alias and cleanup memory rules (full-state, `ZigLean/Sep/Full/Try.lean`; the legacy `Sep/TryAlias.lean` is deleted): every pointer try on one union returns the same payload address or the original error, loads/stores through it act in place without writing the tag; applied to the retained compiler-exported `writeAlias`, `cleanup` (distinct and shared counters) and `coldPayload`; two hand-written-AIR functions (`twoPaths` over one or two unions, `resetOnError` with errdefer cleanup) with proofs, runtime cases and native tests. [PR135](https://github.com/riventic/air2lean/pull/135): the alias fixtures are compiler exports (`air-fresh` and `aliases/air-fresh`, unmodified schema-12 exports of `try_pointers.zig` and `try_aliases.zig` from a patched 0.16.0 compiler; `compiler-qualification.json`/`.py` record hashes, profile, tags and the retained translation) and translate body-identically to the retained hand-written-AIR translations; `check.sh --check-qualification` and unit tests gate them. Batch D (PR "Roadmap batch D: L08 L07 T03 L04"): exports of both fixtures by patched 0.14.1, 0.15.2 and 0.17.1 compilers translate body-identically to the retained modules (`compiler-qualification.json` `versions`); `lifetimes/try_lifetimes.zig` (all four versions): a heap union freed by its `errdefer` after the pointer try captured the error (no heap block stays live, kernel-checked), a payload pointer of a freed union (use after free, `.illegal`), payload pointers shared by threads (reads of one union, writes of two) with the native results under 32 scheduler oracles, and a write racing a read of one payload (`.illegal` on every schedule); the tests of `try_pointers.zig`, the alias fixture `try_aliases.zig` and `try_lifetimes.zig` pass natively on x86_64-linux for 0.14.1-0.17.1, ReleaseSafe and Debug. Concurrent rules (PR "L04: pointer try on read shares and in threads"): full-state rules for every pointer-try operation on a shared union (`spts` read shares: `tryPayloadPtr`, `errCodeAt`, their finite-domain forms, the whole-object read, the payload load) and thread-locality providers for each of them on owned and shared unions (`ReadsPtr`, `ThreadLocal.loadBytesOwned`), so `fsym` walks the thread bodies of `lifetimes/try_lifetimes.zig` as thread steps (`readPayload` on a shared union, both outcomes; `writePayload` on an owned union), all four versions. Payload shapes (PR "L04: alias and cleanup rules for every payload shape"): `lifetimes/try_payloads.zig` repeats the alias and cleanup functions (`writeAlias`, `cleanup` with distinct and shared counters, `resetOnError`) for `u16`, `u32`, `u64`, a struct payload and an `anyerror` union; patched-compiler exports of all four versions; every function has a total full-state triple for both outcomes, proved by `fsym` with the general rules (no rule per payload type), runtime cases with the native tests' values, and native tests on x86_64-linux for 0.14.1-0.17.1, ReleaseSafe and Debug. Remaining: a payload accessed at another element type (`*u32` as `*[4]u8`: it translates, but `fsym` has no rule that exposes the payload of an owned union as a cell of its own; a cast that keeps the element size is covered), general rules for the freed-union case (the fixture frees through the hand-written `Zig.Allocator` model, so it needs translated allocator code first) and the spawn/join composition of the concurrent cases (`CTriple`; checked by schedules), `errSetOk` in a thread. Not modelled, rejected by the translator: overlapping unequal unions (they need a pointer cast that exposes the error code as bytes, which needs finalized error ordinals).
