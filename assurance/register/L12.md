Wholly undefined stores to locals are dead stores or byte locals whose undefined bytes read as `.unspecified` ([PR124](https://github.com/riventic/air2lean/pull/124), soundness fix). [PR172](https://github.com/riventic/air2lean/pull/172): pointer-bearing `threadlocal` storage (`Io.Threaded`'s `threadlocal var current: ?*Thread`) passes the ordinary global-initializer checks; `tls_pointers.zig` exports for 0.15.2–0.17.0 (0.14.1's constant TLS address stays rejected) run under 16 schedules equal to the native probe, a dead thread's instance read through a leaked pointer is `.illegal`, and two mutants are killed. Pointer-bearing `extern` globals: their initial values are `Zig.Ptr` fields of `ext`, and `ExternInit.storage : List Zig.ExternBlock` lists the external blocks that `mem0` adds after the program's globals (`Mem.ofGlobals_extern`); function pointers, unions, error storage and pointer-bearing externs beside error-bearing globals stay rejected. Source/native correspondence: `extern_storage.zig` is linked natively with `provider_extern_storage.c` and the translation runs with the provider's definitions and static storage as `ext` (equal on 0.14.1–0.17.0); `ProofsExternStorage.lean` proves the initialization order and `slotValue` from program start for every placement and every external state of that shape; negative tests and a killed mutant (`mem0` without the external storage). Scope: error-bearing `extern`/`threadlocal` storage, `extern threadlocal`, external writes during the run and dynamic linking stay rejected or unmodelled.
