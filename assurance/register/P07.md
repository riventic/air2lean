title: Proof-friendly and stable generation
status: partial
row: PR93 deterministic names and PR94 scalar stable proof API merged. [PR120](https://github.com/riventic/air2lean/pull/120): air2lean --source-map-json writes a per-function source-map sidecar bound to its Lean output; scripts/semantic-fingerprints.py computes renumbering-invariant fingerprints folded over call-graph SCCs and an invalidation checker reports exactly the changed functions, their cycles and callers. [PR126](https://github.com/riventic/air2lean/pull/126): `--proof-api` emits source-named unfolding lemmas for every function (pure, memory, concurrent, error-returning, recursive) and per-loop body/again/body-unfold/step lemmas, proved by `rfl`, `eq_def` or `Zig.loop.eq_1` and indexed by an `air2lean-proof-lemmas-v1` record; renumbering and an unrelated generic instance keep lemma names and statements while a semantic change alters only that function's; sidecar v2 carries a build-time translator revision (digests of the CLI and every imported `Air2Lean` module) that is part of every fingerprint, and I04's module keys are bound to it. [PR154](https://github.com/riventic/air2lean/pull/154): every loop also gets a `B_loop<k>_spec` lemma, the loop specification rule of the function's monad (`Zig.loop_spec`, `Zig.loop_spec_mm`, `Zig.Conc.Proto.WP.loop`) instantiated at the loop's stable body and repeat test, so a client states an invariant, a measure and a post-condition and proves one iteration, with no reference to `<fn>.loop<id>`; kernel checked on the committed golden examples (pure, memory, concurrent, recursive loops) and renamed with the other loop names (`air2lean-proof-lemmas-v1` gains `spec`); sidecar v3 and the I04 manifest v3 carry a build-time runtime revision (digests of every `ZigLean` module in the import closure of `import ZigLean`, which each generated module imports) that is part of every fingerprint and module key, so a runtime change invalidates every proof interface (`runtime_changed`). Remaining: the spec lemma restates the library rule (the invariant and measure stay the client's); the runtime revision covers the closure of `import ZigLean`, not proof libraries beyond it (`ZigLean.Sep`, `ZigLean.Conc.Spec`), which the I07 manifest's `runtime` link and proof rebuilds cover.
